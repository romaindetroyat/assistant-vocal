# Plan 02-01 — Orchestration MCP et conversation

**Phase**: 2 · **Requirements**: ORC-01..06 · **Depends on**: 01-01

## Tasks

1. **Config MCP** — `server/mcp.js` lit `mcp.config.json` (`servers[]`: name, url, description,
   authorization_token_env) → `mcp_servers` + `tools: mcp_toolset[]` ; validation claire au démarrage.
2. **Prompt système** — `server/prompt.js` : identité, date/heure Europe/Paris, liste des serveurs avec
   leur rôle, règles de choix d'outil (agir sans redemander quand c'est clair, résumer court pour la voix).
3. **Store** — `server/store.js` : conversations JSON dans `DATA_DIR` (liste, lecture, append, création).
4. **Chat** — `server/chat.js` : `POST /api/chat` → SSE. Boucle : `client.beta.messages.stream` avec
   `betas: ["mcp-client-2025-11-20", "server-side-fallback-2026-07-01"]`, `fallbacks: "default"`,
   `output_config.effort`, outils locaux + MCP + web_search ; exécution des outils locaux ; `pause_turn`
   relance ; `response.content` complet ré-ajouté à l'historique (thinking + blocs MCP).
5. **Front** — `public/app.js` : liste des conversations, envoi, rendu streaming, badges d'outils.
6. **Tests** — `test/mcp.test.js` (config → paramètres), `test/chat.test.js` (boucle avec client simulé).
