# Plan 03-01 — Entrées multimodales

**Phase**: 3 · **Requirements**: IN-01..05 · **Depends on**: 02-01

## Tasks

1. **Dictée** — Web Speech API (`fr-FR`, continu, résultats intermédiaires) ; envoi automatique après
   silence ; bouton micro avec état ; repli explicite si non supporté (IN-01, IN-05).
2. **Images** — collage (`paste`), bouton pièce jointe / appareil photo (`capture=environment`),
   redimensionnement canvas ≤ 1568 px, envoi base64 (`image` block) (IN-03).
3. **Vocaux** — MediaRecorder → `POST /api/transcribe` → service HTTP configurable
   (`TRANSCRIBE_URL`, `TRANSCRIBE_API_KEY`, `TRANSCRIBE_MODEL`, format multipart OpenAI-compatible) ;
   501 explicite si non configuré (IN-04).
4. **Texte** — zone de saisie auto-redimensionnée, Entrée = envoyer, Maj+Entrée = retour (IN-02).
