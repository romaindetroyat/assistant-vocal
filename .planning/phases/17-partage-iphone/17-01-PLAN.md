# Plan 17-01 — Partager vers l'assistant depuis l'iPhone (et les autres appareils)

## Objectif
Depuis n'importe quelle app de l'iPhone (Safari, Mail, Photos, Notes…), « Partager → Assistant » envoie une page, un
texte, une image ou une capture à l'assistant avec une consigne optionnelle (« résume », « ajoute à mes tâches », « mets-le
dans l'agenda »). Sans consigne, l'assistant déduit l'action. Le résultat arrive en notification push et dans une
conversation « Partages ».

## Décisions
- **iPhone : Safari ne prend pas en charge Web Share Target.** Le partage passe par un **raccourci iOS** présent dans la
  feuille de partage (entrée : URL, texte, image) qui appelle `POST /api/partage` avec un **jeton d'appareil**.
  Le raccourci demande la consigne (« Que faire ? », facultatif) puis envoie ; la réponse est énoncée par Siri et
  reçue en push. C'est le même mécanisme que les raccourcis Siri (phase 18), d'où la création des jetons ici.
- **Android / ordinateur** : `share_target` dans `manifest.webmanifest` (POST multipart, `title`, `text`, `url`,
  `files` images) traité par le service worker → `/app?partage=<id>` : la PWA installée apparaît dans le menu Partager.
- **Jetons d'appareil** : `server/jetons.js`, jetons aléatoires (32 octets, hex), nom, création, dernier usage,
  révocation ; stockés hachés (SHA-256) ; acceptés en `Authorization: Bearer` sur `/api/partage` et `/api/raccourci`
  (phase 18) uniquement. Gérés dans « Mes outils › Appareils et raccourcis ».
- **Traitement** : `POST /api/partage` (multipart ou JSON : `texte`, `url`, `consigne`, `fichier` image) crée ou réutilise
  la conversation « Partages », compose le message utilisateur (texte + image + « Consigne : … » ou « Fais ce qui est
  le plus utile : résumé court, tâche ou rendez-vous si une date apparaît »), exécute `executerTour` avec effort voix,
  renvoie `{ texte, conversationId }` et envoie un push « Partage traité » (corps = réponse tronquée, url de la
  conversation). Pour une URL sans texte, l'assistant utilise `web_search`/lecture via l'outil web existant.

## Tâches
1. `server/jetons.js` (création, vérification, révocation, hachage) + routes `GET/POST/DELETE /api/jetons` + middleware
   `authJeton` dans `app.js` ; tests.
2. `server/partage.js` : `traiterPartage({ client, serveurs, nonConnectes, texte, url, consigne, image })` ; route
   `POST /api/partage` (cookie **ou** jeton) ; test (image + texte, URL seule, consigne).
3. PWA : `share_target` dans le manifeste, interception POST dans `sw.js` (stocke dans le Cache API puis redirige vers
   `/app?partage=…`), `app.js` lit le partage et l'envoie comme message normal avec les images. `CACHE` v19.
4. « Mes outils › Appareils et raccourcis » : liste des jetons, création nommée (jeton affiché une seule fois), révocation,
   et **guide illustré du raccourci iOS « Partager avec l'assistant »** (étapes Raccourcis : Recevoir l'entrée de la
   feuille de partage → Demander une saisie → Obtenir le contenu de l'URL POST JSON/multipart → Énoncer le texte).
5. `.planning` : SUMMARY, STATE, ROADMAP.

## Vérifications
- `npm test` vert ; un `curl` avec jeton et une image renvoie le résumé et un push part.
- Test réel iPhone par Romain : partager un article Safari → résumé lu par Siri + notification.
