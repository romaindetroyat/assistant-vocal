# Plan 01-01 — Socle : serveur, authentification, PWA

**Phase**: 1 · **Requirements**: ACC-01, ACC-02, ACC-03 · **Depends on**: —

## Tasks

1. **Projet Node** — `assistant/package.json` (ESM, Node ≥ 22), dépendances : hono, @hono/node-server,
   @anthropic-ai/sdk, web-push. Scripts `start`, `dev`, `test`, `vapid`.
2. **Serveur** — `server/index.js` : Hono, fichiers statiques `public/`, routes `/api/*`, port `PORT`.
3. **Auth** — `server/auth.js` : `POST /api/login` compare à `ASSISTANT_PASSWORD` (timing-safe), pose un
   cookie HMAC (`SESSION_SECRET`) HttpOnly/SameSite=Lax/Secure ; middleware qui protège `/api/*` sauf login.
4. **PWA** — `public/index.html`, `styles.css`, `manifest.webmanifest`, `sw.js` (cache de l'app shell,
   réseau pour `/api`), icônes SVG. Écran de connexion intégré.
5. **Test** — `test/auth.test.js` : login refusé/accepté, cookie valide, `/api/me`.

## Verification

- `npm test` vert ; `npm start` puis `curl -i localhost:3000/api/me` → 401 sans cookie.
