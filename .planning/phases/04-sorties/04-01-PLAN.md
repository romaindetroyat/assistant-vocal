# Plan 04-01 — Sorties : voix, notifications, rappels

**Phase**: 4 · **Requirements**: OUT-01..04 · **Depends on**: 03-01

## Tasks

1. **Voix** — `speechSynthesis` avec voix `fr-FR`, lecture de la réponse finale (texte nettoyé du
   markdown), bouton haut-parleur persistant (localStorage) (OUT-01).
2. **Push** — `server/push.js` : VAPID (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`),
   `GET /api/push/key`, `POST /api/push/subscribe`, abonnements en store ; `sw.js` affiche la notification
   et ouvre l'app au clic (OUT-03).
3. **Outils locaux** — `server/tools.js` : `notify_me`, `schedule_reminder`, `list_reminders`,
   `cancel_reminder` ; `server/scheduler.js` vérifie les rappels dus toutes les 20 s (OUT-04).
4. **E-mail / messages** — pas de code : le prompt système oriente vers les serveurs MCP mail/messagerie
   déclarés dans la config (OUT-02).
