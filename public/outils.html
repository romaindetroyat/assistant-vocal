Outils connectés

Gmail (connexion Google directe)

Première fois : il faut un identifiant OAuth Google (console.cloud.google.com → APIs et services → Identifiants → Créer → ID client OAuth, type « Application Web »). Adresse de redirection à déclarer : . Activez aussi l'API Gmail dans le projet.

Catalogue : connexion en un clic

Choisissez un service, autorisez-le dans votre navigateur, c'est tout. Gmail, Google Agenda et Google Drive passent par Zapier.

Autre serveur MCP (avancé)

Collez l'adresse du serveur MCP. S'il demande une autorisation (OAuth), un bouton « Connecter » apparaîtra. S'il fournit un jeton, collez-le ci-dessous.

Utiliser l'assistant depuis claude.ai (serveur MCP)

Dans claude.ai : Paramètres → Connecteurs → Ajouter un connecteur personnalisé, puis collez cette adresse. L'autorisation se fait avec votre mot de passe de l'assistant.
